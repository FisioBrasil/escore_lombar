END/NPRS - Escala Numérica de Dor

Pergunta prática: qual é a intensidade da dor lombar agora, de 0 a 10? Zero representa sem dor e 10 a pior dor imaginável.

Normalização para o ELI--END x 10

PSFS - Escala Funcional Específica do Paciente

Escolha 3 a 5 atividades importantes para este paciente. Cada atividade vai de 0 a 10, onde 0 é incapaz de realizar e 10 é capaz como antes.

Limitação funcional--(10 - média) x 10

ODI - Oswestry Disability Index

Marque 0 a 5 em cada domínio conforme a alternativa selecionada no questionário oficial. Deixe em branco se o item não foi respondido; o percentual ajusta o denominador.

STarT Back Screening Tool

Marque as respostas como ausente/não ou presente/sim. Os itens 5 a 9 formam a subescala psicossocial usada na estratificação de risco.

Classificação----

EQ-5D-3L

Sistema descritivo com 5 dimensões e 3 níveis. Esta ferramenta não calcula utilidade oficial; usa uma severidade simples e a EQ VAS invertida para compor o ELI.

EQ norm 0-100----
EQ VAS
Autoavaliação global de saúde hoje: 0 = pior saúde imaginável; 100 = melhor saúde imaginável.
